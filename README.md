# 🚗 University Parking System 🏫  
**A simple & efficient solution for managing university parking spaces**  

---

## 📌 Features  
✅ **Google Maps Integration** – Locate parking slots easily  
✅ **User Authentication** – Secure login for  staff  
✅ **Admin Panel** – Manage slots & reservations  
✅ **Live Slot Availability** – Real-time updates on parking status  

---
